# Secret Scanner Tool

A web-based security tool that scans uploaded files to detect accidentally exposed sensitive information such as passwords, API keys, access tokens, GitHub tokens, AWS access keys, JWT tokens, and other secret credentials. The application helps developers identify potential security risks before sharing or deploying code.

---

##  Features

-  Scan one or multiple files
-  Detect exposed passwords
-  Detect API keys
-  Detect GitHub Personal Access Tokens
-  Detect AWS Access Keys
-  Detect Google API Keys
-  Detect JWT Tokens
-  Detect Bearer Tokens
-  Dashboard with scan summary
-  High & Medium severity classification
-  Download scan report as JSON
-  Responsive and user-friendly interface

##  How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Launch `index.html` using Live Server (or open it directly in your browser).
4. Upload one or more files.
5. Click **Scan Files**.
6. Review the detected secrets.
7. Download the JSON report if required.
